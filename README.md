# AppCloner

Клонатор приложений для Android без рекламы.

## Возможности

- Просмотр списка установленных приложений
- Поиск по названию или пакету
- **Клонирование с изменением package name** (использует ARSCLib)
- Установка клонированных APK
- Шаринг APK через другие приложения
- Просмотр информации о приложении

## Как работает клонирование

1. Извлекает APK установленного приложения
2. Парсит `AndroidManifest.xml` с помощью **ARSCLib** (надёжный парсер бинарного XML)
3. Изменяет package name в манифесте
4. Сохраняет модифицированный APK
5. Позволяет установить клон

## Зависимости

| Библиотека | Назначение |
|------------|------------|
| `com.reandroid:ARSCLib` | Парсинг и модификация бинарного XML Android |
| `net.dongliu:apk-parser` | Чтение метаданных APK |
| `com.android.tools.build:apksig` | Подпись APK |

## Сборка

1. Откройте проект в Android Studio
2. Дождитесь синхронизации Gradle
3. Нажмите Run или используйте `./gradlew assembleDebug`

## Архитектура

```
app/src/main/java/com/appcloner/
├── MainActivity.java        # Главный экран
├── AppAdapter.java          # Адаптер для списка
├── AppInfo.java             # Модель данных
└── ArsclibApkCloner.java    # Основной класс клонирования (ARSCLib)
```

## Ограничения

- Некоторые приложения с защитой могут не работать после клонирования
- Банковские приложения требуют оригинальный package name
- WhatsApp и подобные требуют отдельный номер телефона

## Требования

- Android 7.0 (API 24) и выше
- Android Studio Arctic Fox или новее
- Gradle 8.2+
